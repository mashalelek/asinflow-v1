## Replit Prompt

Build a full-stack Amazon FBA profitability analyzer web app with the following specifications:

---

### Stack
- **Frontend:** React (with Tailwind CSS, dark mode theme)
- **Backend:** Node.js / Express
- **File parsing:** `xlsx` and `papaparse` libraries
- **Amazon data:** Amazon SP-API (US marketplace — `ASIN1`)

---

### Core Features

#### 1. CSV/Excel Upload
- Allow the user to upload a `.csv` or `.xlsx` file with exactly 2 columns: `ASIN` and `COGS`
- Parse the file on the backend and extract the ASIN list

#### 2. SP-API Integration
For each ASIN, call the following SP-API endpoints:
- **Pricing API** (`getItemOffers` or `getCompetitivePricing`) to retrieve:
  - Lowest FBA price
  - Buy Box price
  - Lowest overall price
  - Number of sellers
- **Product Fees API** (`getMyFeesEstimate`) to retrieve:
  - FBA fulfillment fee
  - Referral fee
- **Catalog Items API** to retrieve:
  - Item weight in lbs (used for inbound shipping cost calculation)

**Price selection logic (in this order):**
- User can toggle between **Lowest FBA Price** (default) and **Buy Box Price**
- If the selected price is unavailable, automatically fall back to **Lowest Price**
- If Lowest Price is unavailable (no sellers on listing), fall back to **30-day average price**
- If 30-day average is unavailable, fall back to **90-day average price**
- If none are available, display `"Not Available"` for that row and skip calculations

#### 3. Profit Calculation (SellerAmp-style)
```
Profit = Sale Price
       − COGS (from uploaded file)
       − FBA Fulfillment Fee (from SP-API)
       − Referral Fee (from SP-API)
       − Inbound Shipping Cost (item weight lbs × inbound $/lb from Settings)
       − Prep Cost (flat $ per unit from Settings)
       − Storage Fee (flat $ per unit from Settings)

ROI             = (Profit ÷ COGS) × 100
Profit Margin   = (Profit ÷ Sale Price) × 100
Profit per Unit = Profit
```

### Output Table
Display results in a styled dark-mode data table with the following columns:

| Column | Notes |
|---|---|
| ASIN | Clickable link to amazon.com/dp/ASIN |
| COGS | From uploaded file |
| Sale Price | Price used for calculation, with label showing which source was used (e.g. "Buy Box", "Lowest FBA", "30d Avg") |
| FBA Fee | From SP-API |
| Referral Fee | From SP-API |
| Inbound Shipping | Calculated |
| Prep Cost | From Settings |
| Storage Fee | From Settings |
| Profit per Unit | Calculated |
| Profit Margin | Calculated, shown as % |
| ROI | Calculated, shown as % |
| # of Sellers | From SP-API |

**Conditional row highlighting:**
- 🟢 Green row: ROI ≥ minimum ROI threshold AND Margin ≥ minimum margin threshold
- 🔴 Red row: ROI < minimum ROI threshold OR Margin < minimum margin threshold
- ⚪ Gray / muted row: Sale price is "Not Available"

### Price Toggle
Add a toggle switch at the top of the results table (or above it) labeled:
**"Price Source: [Lowest FBA] / [Buy Box]"**
- Switching the toggle should instantly recalculate all rows using the newly selected price source without re-fetching from the API (cache both values per ASIN)

### Export Options
Add two buttons above the results table:
- **Download CSV** — exports all result rows as a `.csv` file
- **Download Excel** — exports all result rows as a `.xlsx` file using the `xlsx` library

### Error Handling
- If SP-API returns an error for a specific ASIN, display the error message in that row rather than crashing the whole batch
- Show a progress indicator (e.g. "Fetching 24 of 100 ASINs...") while the batch is being processed
- Rate limit SP-API calls to avoid throttling — process ASINs in batches of 10 with a 1-second delay between batches
